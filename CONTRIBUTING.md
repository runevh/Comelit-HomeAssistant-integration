# Contributing

Use Python 3.14 and the development environment described in README.md.
Run `scripts/lint` and the tests documented in README.md before submitting a pull request, and include relevant
validation for behavior changes. Contributions are licensed under MIT.

Never include tokens, passwords, activation codes, gateway backups, or
unredacted diagnostic payloads in commits or issues. Coordinate live actuator
and doorbell tests with the owner before running them.
